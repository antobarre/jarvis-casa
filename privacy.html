Informativa sulla privacy — Jarvis Casa

Ultimo aggiornamento: 15 ottobre 2026 · English version below

Chi siamo

Jarvis Casa è un assistente personale sviluppato e usato da una sola persona, Antonino Barreca, per uso privato e familiare. Non è offerto ad altri utenti.

Quali dati Google vengono usati

Con il consenso dell'unico utente (il proprietario dell'account servizi.barreca@gmail.com) l'applicazione accede in sola lettura a:

  • messaggi di Gmail,
  • eventi di Google Calendar,
  • file di Google Drive.

Come vengono usati

I dati sono letti soltanto per rispondere alle richieste del proprietario (per esempio riassumere la posta del giorno o ricordare un appuntamento). Non sono usati per pubblicità, profilazione o addestramento di modelli, non sono venduti e non sono condivisi con terzi.

L'elaborazione avviene su un computer privato del proprietario, in rete domestica, con un modello linguistico eseguito in locale. Il risultato (un riassunto o una risposta) viene inviato al proprietario sulla sua conversazione Telegram. Telegram è quindi l'unico servizio esterno che riceve il testo delle risposte.

I contenuti non sono conservati in modo permanente oltre alla memoria di lavoro dell'assistente sul computer del proprietario, che può essere cancellata in qualsiasi momento.

Google API Services User Data Policy

L'uso e il trasferimento a qualsiasi altra app delle informazioni ricevute dalle API di Google rispetteranno la Google API Services User Data Policy, inclusi i requisiti di Limited Use.

Revoca dell'accesso e cancellazione

Il proprietario può revocare l'accesso in qualsiasi momento da myaccount.google.com/permissions. Alla revoca l'assistente non può più leggere i dati e i token salvati vengono eliminati dal computer.

Privacy policy — Jarvis Casa

Last updated: 15 October 2026

Who we are

Jarvis Casa is a personal assistant built and used by a single person, Antonino Barreca, for private and family use. It is not offered to other users.

Google data used

With the consent of the only user (the owner of the account servizi.barreca@gmail.com) the application accesses, read-only: Gmail messages, Google Calendar events and Google Drive files.

How it is used

Data is read only to answer the owner's requests (for example summarising the day's mail or reminding an appointment). It is not used for advertising, profiling or model training, it is not sold and it is not shared with third parties. Processing happens on a private computer owned by the user, on a home network, with a language model running locally. The result is sent to the owner in their Telegram conversation; Telegram is the only external service that receives the text of the answers. Content is not stored permanently beyond the assistant's working memory on the owner's computer, which can be erased at any time.

Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke access at any time at myaccount.google.com/permissions. After revocation the assistant can no longer read the data and the stored tokens are deleted from the computer.
